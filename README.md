# 🚀 TaskFlow Pro v5 - PWA Phitsanulok
**ระบบบริหารจัดการภารกิจและติดตามงานภายในองค์กร** ออกแบบและพัฒนาสำหรับ การประปาส่วนภูมิภาคสาขาพิษณุโลก (กปภ.สาขาพิษณุโลก)

---

## 🌟 ฟีเจอร์หลัก (Key Features)
* **Real-time Dashboard:** สรุปสถานะงานในหน้าเดียว (WIP, เสร็จสิ้น, รอตรวจ, อุปสรรค)
* **Task Management:** ระบบมอบหมายและติดตามความคืบหน้างาน
* **Personalized Profile:** แสดงผลรูปโปรไฟล์พนักงานจริง
* **Database Integration:** เชื่อมต่อฐานข้อมูล MySQL สมบูรณ์
* **Mobile Responsive:** รองรับการใช้งานผ่านมือถือและแท็บเล็ต

---

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP 8.2
* **Database:** MySQL / MariaDB
* **Environment:** XAMPP for macOS

---

## 📂 โครงสร้างโฟลเดอร์ (Folder Structure)
```text
taskflow/
├── php/              # API และการเชื่อมต่อฐานข้อมูล
├── sql/              # ไฟล์ Schema ฐานข้อมูล (.sql)
├── uploads/          # รูปโปรไฟล์และไฟล์แนบ
├── index.html        # หน้า Dashboard หลัก
└── README.md         # เอกสารอธิบายโปรเจกต์
```
