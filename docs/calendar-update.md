# ปรับปฏิทินและกำหนดการหลายวัน

ใช้กับ vercel-static (หน้าปฏิทินในภาพ) และ Supabase

1. สำรองฐานข้อมูล แล้วรัน supabase/calendar-date-range.sql ใน Supabase SQL Editor ก่อน deploy
2. Deploy โฟลเดอร์ vercel-static ตามการตั้งค่า Vercel เดิม
3. เปิดปฏิทิน กดเพิ่มประชุม/อบรม เลือกวันที่เริ่มต้นและวันที่สิ้นสุด (นับรวมทั้งสองวัน)
4. บันทึกแล้วโหลดหน้าใหม่ ตรวจว่ารายการอยู่ครบทุกวัน และแก้ไขช่วงวันได้

งานปกติสามารถเว้นวันที่เริ่มต้นไว้ได้ วันสิ้นสุดยังใช้เป็นวันกำหนดส่งเดิม
บนมือถือเลื่อนตารางแนวนอนได้ และดูชื่อเต็มในรายการงานใต้ปฏิทิน

ตรวจสอบแล้ว: syntax JavaScript, date ranges, cross-month, leap day, legacy dates (node tests/calendar.cjs)
ยังไม่ได้ทดสอบกับฐานข้อมูลจริงหรือ deploy ไปยังระบบที่ใช้งานอยู่
